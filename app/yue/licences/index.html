Licences

The Cantonese app is made of separately licensed files. Each data file in data/ carries its own licence in a licence line, and the same lines are shown below. Source code and the scripts that build every data file are in the project's repository.

App code and lesson text

index.html, app.js, state.js, drills.js, lesson.js, jyutping.js, tones.js, audio.js, speak.js, speech.js, lexicon.js, course.js, wordlesson.js, today.js, sounds.js, type.js, read.js, search.js, map.js, yue.css, sw.js and data/stage0.json, data/tonecheck.json, data/keyboards.json: MIT. Licence text.

Data file notice: data/stage0.json says “MIT: Jiesuo”; data/tonecheck.json says “MIT: Jiesuo (computed)”; data/keyboards.json says “MIT: Jiesuo”, with its setup steps summarised from the pages it cites.

The lesson text cites its sources in the file: Matthews and Yip, Cantonese: A Comprehensive Grammar (2nd ed., Routledge 2011), and the Linguistic Society of Hong Kong's Jyutping scheme.

Readings: data/readings.json

Data file notice: “CC BY-SA 4.0: readings from rime-cantonese (CC BY 4.0), checked against CC-Canto (CC BY-SA 3.0), Unihan, HKCanCor (CC BY 4.0)”. The file is shared under CC BY-SA 4.0, because it builds on CC-Canto. Changes: we kept only the characters the lessons use, and only well-attested readings. The ODbL .maps file of rime-cantonese is not used.

Recorded syllables: audio/ and data/audio.json

Data file notice: “MIT: Cantone (AlienKevin/cantone), synthetic voices from Amazon and Google”. The clips are computer-generated voices, not people. They are from the Cantone dataset by Kevin Li, MIT licence. Changes: we kept the syllables the lessons use and re-encoded them as mp3 files. The voice shipped is googleB, a synthetic voice from Google.

Neural voice clips: data/speech.json and audio/speech/

These clips, when present, were generated with Azure Speech zh-HK neural voices (HiuMaan and WanLung) from our own Jyutping readings. They are computer-generated voices, not people. The sentence texts they speak keep their own licences, shown above.

Font: Noto Serif HK

Hong Kong forms of the characters are set in Noto Serif HK (Noto Serif CJK), loaded from Google Fonts, and used for the app icon. Copyright Google and Adobe, SIL Open Font License 1.1. Licence text.

Words and course: data/lexicon.json, data/course.json

Both files say “CC BY-SA 4.0” in their licence line. The word list builds on the readings sources above and on CC-CEDICT (CC BY-SA 4.0) and CC-Canto for meanings. They contain no words.hk text.

Tatoeba sentences: data/sentences.json

Sentences from Tatoeba, Creative Commons Attribution 2.0 France (CC BY 2.0 FR). Each sentence names its author, and the author of its English translation, in the file. We added the Jyutping. Notice.

Spoken sentences: data/hkcancor.json

Sentences from HKCanCor, CC BY 4.0. Licence text.
